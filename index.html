HTML,CSS Y JAVASCRIPT:

Son los tres pilares fundamentales del desarrollo web que trabajan juntos para crear páginas web dinámicas e interactivas
HTMLse encarga de la estructura y el contenido, CSS del diseño y la presentación y JavaScriptde la interactividad y la funcionalidad.

Definiciones:

HTML(HyperText Markup Language):

Es el lenguaje de marcado que define la estructura y el contenido de una pagina web. utiliza etiquetas para delimitar deferentes elementos, como párrafos, encabezados, imagenes, enlaces, etc.

CSS(Cascading Style Sheets):

Es un lenguaje de estilosque utiliza para controlar la presentación de una pagina web. Permite definir aspectos como los colores, fuentes,tamaños, márgenes, etc, de los elementos HTML.

JavaScript(Program language):

Es un lenguaje de programación que permite agregar funcionalidad interactiva a una pagina web. Permite manipular elementos HTML responder a eventos del usuario, realizar calculos, etc.

Analogia de una web y una casa:

HTML

Estructura de la casa.

Es como los cimientos, las paredes, techos y distribución de las habitaciones.

HTML define la estructura basica de una pagina web que elementos hay(titulo,párrafo, botones, imagenes,etc) pero sin preocuparse por como se ven.

CSS

Decoración y estilo de la casa.

Es la pintura de las paredes, el tipo de piso, los muebles, las cortinas, el diseño de la cocina.

CSS se encarga de como se ve la pagina: colores, fuentes, margenes, alineaciones, estilos, responsivos...lo visual.

JS

Los sistemas eléctricos y eletrónicos de la casa.

Es como los interruptores que encienden luces, las puertas automáticas, el termostato inteligente.

JavaScript añade funcionalidad e interactividad haciendo que pasen cosas como respuesta a un evento.


Resumen:

"Los tres lenguajes son esenciales para el desarrollo web y cada uno juega un papel crucial en la creación de paginas web modernas y funcionales."
